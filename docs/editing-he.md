# איך לעדכן את האתר בעזרת AI (בלי לכתוב קוד)

האתר שלך חי ב־GitHub (המאגר `itay-shechter-portfolio`). כל שינוי שנשמר שם עולה לאוויר
לבד תוך דקה בערך, דרך Vercel. אם משהו נשבר בבנייה, הגרסה הקודמת נשארת באוויר, כך
שאי אפשר "להפיל" את האתר בטעות.

כל הטקסטים, המספרים, הקישורים והסרטונים נמצאים בקובץ אחד:
**`src/content/site.ts`**. התמונות נמצאות בתיקייה `src/assets/`.

יש שלוש דרכים לעבוד, מהפשוטה למתקדמת.

---

## דרך 1: הצ'אט הרגיל של ChatGPT (הכי פשוט)

### חיבור חד פעמי

1. ב־ChatGPT: הגדרות (Settings), ואז Apps (או Connectors), ואז GitHub, ואז Connect.
2. GitHub יבקש אישור. כשהוא שואל לאילו מאגרים לתת גישה, בחר **רק** את
   `itay-shechter-portfolio`.
3. בצ'אט חדש, לחץ על ה־**+** ליד תיבת הכתיבה ובחר GitHub (או פשוט כתוב
   "תשתמש ב־GitHub"), כדי שהצ'אט יקרא את המאגר.

### עדכון

פשוט כתוב מה אתה רוצה, במילים שלך. למשל:

> באתר שלי ב־GitHub (itay-shechter-portfolio): תשנה את מספר העוקבים בטיקטוק ל־160K.

או:

> באתר שלי ב־GitHub (itay-shechter-portfolio): שיהיה לטלפון זוהר עדין כשעוברים עליו עם העכבר.

מה יקרה:

1. הצ'אט עושה את השינוי ושולח לך **קישור לתצוגה מקדימה**: האתר שלך עם השינוי,
   לפני שהוא עולה באמת.
2. פתח את הקישור (גם בטלפון) ותסתכל.
3. אם משהו לא מוצא חן בעיניך, תגיד לו מה לשנות, והוא ישלח תצוגה חדשה.
4. אם הכל טוב, תכתוב **"כן, תעדכן את האתר"**. אחרי דקה בערך זה באתר.

כל עוד לא אמרת כן, האתר באוויר לא משתנה.

אם במקום זה הצ'אט נותן לך טקסט להדביק (קורה כשהחיבור מאפשר לו רק לקרוא):

1. פתח באתר github.com את המאגר, ואז את הקובץ `src/content/site.ts`.
2. לחץ על סמל העיפרון (Edit).
3. מצא את השורה (Ctrl+F, או בטלפון: חיפוש בדף), החלף אותה בטקסט שקיבלת.
4. לחץ **Commit changes**, ושוב Commit changes בחלון שנפתח.
5. אחרי דקה, רענן את האתר.

טיפ: אם הצ'אט נותן קטע ארוך, בקש ממנו "רק את השורות שמשתנות, לפני ואחרי".

## דרך 2: Codex בתוך ChatGPT (לשינויים גדולים יותר)

Codex הוא הכלי של ChatGPT שעובד ישירות על הקוד. הוא כלול באותו מנוי.

1. ב־ChatGPT, פתח את Codex (בתפריט הצד, או chatgpt.com/codex) וחבר את GitHub
   עם אותו מאגר.
2. כתוב מה אתה רוצה, למשל:
   > תוסיף לקרוסלה סרטון טיקטוק חדש: <קישור>. כותרת: ... תיאור: ... תעקוב אחרי AGENTS.md.
3. Codex פותח **Pull Request** (הצעת שינוי). אחרי דקה Vercel מוסיף אליו
   **קישור לתצוגה מקדימה**: האתר עם השינוי, לפני שהוא עולה באמת.
4. פתח את הקישור בטלפון ובדוק. אם הכל טוב, לחץ ב־GitHub על **Merge**. זהו, באוויר.

ככה גם תמונות חדשות (תמונה לסרטון, תמונת פרופיל) עובדות הכי טוב.

  הבדיקה האוטומטית תיכשל עליהם.

- תמונות: תמונה לסרטון ברוחב 600 פיקסלים בערך, תמונת פרופיל 640x640.
  תמונה ענקית מאטה את האתר בטלפון.

## משהו השתבש?

- **הבנייה נכשלה:** האתר הקודם נשאר באוויר. תעתיק לצ'אט את הודעת השגיאה
  (מ־GitHub, לשונית Actions, או מ־Vercel) ותבקש ממנו לתקן.
- **עלה שינוי שלא רצית:** הכי מהיר: ב־Vercel, Deployments, בוחרים את הגרסה
  הקודמת ולוחצים **Promote to Production**, וזה חוזר מיד. אחר כך מבקשים מהצ'אט
  להחזיר את השינוי גם בקובץ, כדי שהעדכון הבא לא יחזיר אותו.
- **לא בטוח?** תשאל את בר.
